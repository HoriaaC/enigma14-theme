# ENIGMA 14 Theme

Custom Full Site Editing (FSE) & Gutenberg block theme designed for **ENIGMA 14 — Centrul Tehnic Specializat de Duplicare și Decodare Chei București**.

## Features
- **Tailwind CSS Engine**: Fast, optimized utility-first styling with custom dark theme mechatronic aesthetic.
- **ACF Blocks & Options**: Fully integrated ACF Pro block system with instant admin previews and editor styling.
- **Auto-Sync ACF JSON**: All field groups version-controlled in `acf-json/`.
- **Dynamic Diagnostics & WhatsApp Integration**: Native Web Share API + server background upload for seamless photo diagnostics.
- **Booking Modal & Interactive Assessment**: Responsive drawer, popup modals, and multi-mode vehicle/residential forms.
- **Under Construction / Maintenance Mode**: One-click toggle in Site Settings with centered visual poster and admin live preview.

## Development
- Compile styles: `npm run build`
- Watch styles: `npm run dev`
